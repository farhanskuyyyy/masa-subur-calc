# 🩷 Kalkulator Masa Subur

Kalkulator masa subur online gratis menggunakan metode kalendar. Perhitungan dilakukan 100% di browser — data tidak pernah dikirim ke server.

## Fitur

- 📅 Hitung hari ovulasi perkiraan
- 🌟 Jendela subur (fertile window)
- 🛡️ Masa kurang subuh (relatif aman)
- 🗓️ Kalender visual 3 bulan
- 📱 Responsive design
- 🔒 Privasi terjaga (client-side only)

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Inter)

## Cara Pakai

1. Buka `index.html` di browser
2. Masukkan tanggal hari pertama haid terakhir
3. Sesuaikan panjang siklus dan lama haid
4. Klik "Hitung Masa Subur"

## Metode

Menggunakan metode kalendar (calendar method):
- **Ovulasi** = Panjang siklus − 14 hari
- **Jendela subur** = 5 hari sebelum ovulasi + ovulasi + 1 hari sesudah
- **Masa aman** = Setelah haid selesai, sebelum jendela subur

> ⚠️ Hasil adalah perkiraan. Untuk hasil akurat, konsultasikan dengan dokter.
